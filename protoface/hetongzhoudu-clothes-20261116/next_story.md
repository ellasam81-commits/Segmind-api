# 第4集《将军，你是不是坏人？》｜45秒创作稿

原创粉丝小剧场，非原著复述、非电视剧已确认情节。小炭火是原创观察视角，不替代原作人物。延续黑甲、暗夜电影感；全程穿衣，轻喜剧放在前半段，后半段由选择和代价推动。

| 时间 | 画面与动作 | 对白／声音 |
|---|---|---|
| 00–05 | 门缝里，黑甲将军将一份名单推给黑衣人。小炭火在廊外听见。名单内容暂不可读。 | 将军：“天亮之前，这些人，一个都不能留。”低弦与纸张摩擦。 |
| 05–12 | 小炭火屏住呼吸，绕到窗边。她藏住身体，火苗却在窗纸上晃。将军从侧面出现，把她带离窗前的视线。 | 小炭火：“你到底是救人，还是害人？”将军：“先把火收一收。”火苗缩小，轻轻一声噗。 |
| 12–21 | 他推开内门：里面是准备转移的受伤者。黑衣人打开包袱，露出药和便服，而非兵器。将军将自己的披风盖在伤者肩上。 | 将军对护送者：“走水路。天亮前出城。”小炭火低声：“原来，是不能留在城里……” |
| 21–30 | 她接过递来的灯，照亮渡口路线。扫过名单后，她发现最下面没有将军的名字。镜头清楚展示她的观察与停顿。 | 小炭火：“送走所有人……那你呢？”音乐收低，只剩远处巡夜梆声。 |
| 30–39 | 远处传来甲片与脚步。他将面具重新戴好，转向巡兵来处；小炭火主动收暗火光，护着伤者向另一侧离开。 | 将军：“我还有一场戏，没演完。”她望着他的背影，无对白。脚步声将悬念带入片尾。 |
| 39–45 | 原有两张真人剧照交替；先面具黑甲，再露出真容。留足演员名字阅读时间。 | 大字：何不同舟渡；次行：檀健次 饰 谢却山；悬念：“他背负的骂名，藏着谁的生路？”小字：AI辅助创作 · 粉丝二创 · 非官方剧情。 |

剪辑：前12秒三次切换形成偷听与被发现的节奏；救人揭示用一个连贯推门镜头，不堆砌快闪；结尾面具动作与真人黑甲照片做形状匹配转场。配乐以低弦、轻鼓为主，笑点只给一次短促火苗声，不用罐头笑声。此稿未启动额外视频生成。
