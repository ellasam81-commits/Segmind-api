# 何不同舟渡 · 将军，你不是受伤了吗？！

Original fan-fiction anime short: a boast of protection turns into a window attack, the injured general protects Xiao Tan Huo, and the attacker recognizes him before escaping. A token leaves the identity question unanswered. These events are explicitly labeled non-official.

Reproduction: retrieve generated assets listed in generation-index.json, run prepare.py, render_story.py, and mix_soundtrack.py. Dependencies: FFmpeg/libass, Python 3, NumPy, SciPy, Noto Sans CJK SC. The script downloads Ma Shan Zheng from its official Google Fonts repository if absent. Place the user-provided music at ../upload/幻火.mp3; the song is not committed here.

The three-second end card identifies Tan Jianci as Xie Queshan, names the series, includes Mango TV reservation text, and labels the fan fiction. Only request.json triggers new paid generation. No regeneration was used for postproduction corrections.
