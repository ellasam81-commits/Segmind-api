# 《十三扇门》第1集：逐镜头提示词

作者 林爱丽。四段各15秒，共36镜头、60秒。

严格按本段9张独立剧情参考图，从上排左中右、中排左中右、下排左中右顺序，制作15秒、16:9、480p二维动漫恐怖悬疑片段。每格单独铺满屏幕，保留原构图、角度和动作，只加自然轻微动作；不展示整张九宫格、标题栏、说明栏、底部表格。沈照夜全程同脸、黑发、黑长外套、高领毛衣、棕色斜挎包；左右以画面为准，右手/左手以人物身体为准，不镜像。只用一把无数字普通铜钥匙；入口门锁自行打开，不能改成用钥匙开门。人物与道具必须连续。

【声音硬性要求】只有沈照夜一个成年男声，普通话清楚、低沉克制。台词是白名单：只说本段被明确列出的逐字台词。标“无对白”的镜头完全不说话，不读纸面文字、不重复地址、不念动作、表情、position、时码或角色名；不加旁白、女声、电话声、歌声。只保留标注音效，无BGM、无字幕。画外对白仍属于画内同一个沈照夜，不改变人物位置，不让道具代说。音色参考只供辨认音色，参考里的话不得当作本段台词。

【制作方式】为避免模型自由发挥台词，视频阶段优先生成动作画面及音效，准确的七句对白由后期分句配音对齐；未做口型修正的镜头不能声称已逐帧同步。该提示词文件是修订说明，不代表已重新生成视频。
