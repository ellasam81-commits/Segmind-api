# QQ Music anime guide — Protoface

Independent 60-second tutorial workflow for the uploaded anime presenter and the user's QQ Music screen-recording steps.

- Provider: Protoface
- Model: `minimax/minimax-h3`
- 5 parts × 12 seconds, 16:9, 480p, native Mandarin audio
- Character stays on the left so the real QQ Music screen recording can be composited on the right.
- Maximum 15 credits per part / 75 credits total.
- No retries that create replacement paid jobs.
- Uses the existing repository secret `PROTOFACE_API_KEY`; the key is never printed.
- This workflow does not import, edit, trigger, or reuse any 《十三扇门》 file, job, artifact, checkpoint, or concurrency group.
