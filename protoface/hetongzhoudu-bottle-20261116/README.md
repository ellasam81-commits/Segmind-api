# 何不同舟渡 · 先把药瓶打开

Second standalone fan comedy. Four generated 12-second clips, edited to a 29.8-second story with a 6.8-second animated Mango TV reservation outro.

Run `prepare.py`, then `polish_wordart.py`, then `mix_soundtrack.py`. Requires FFmpeg/libass, Python, NumPy, SciPy, Noto Sans CJK SC and the user-supplied `../upload/游爱场.mp3`. The brush font is downloaded from its official Google Fonts repository if missing. Raw scene files are retrieved from the generated assets listed in generation-index.json. Music uploads are not included in this repository.

Regeneration is not necessary for editing. Only changes to request.json trigger the isolated paid-generation workflow.
