# Protoface from your phone

This manual GitHub Actions workflow calls the Protoface API. No computer,
terminal, or always-on server is needed. It does **not** install an MCP tool in
ChatGPT. GitHub runs the code when you tap **Run workflow**.

## 1. Save your key once

1. Open [Protoface](https://app.protoface.com) and create an API key. Copy the
   **full secret**, not the short identifier. A scoped key needs `runs:read`
   and `runs:write` to retrieve and generate videos.
2. Open this repository in Safari or Chrome, then **Settings → Secrets and
   variables → Actions → New repository secret**.
3. Name: `PROTOFACE_API_KEY`. Secret: paste your full Protoface key. Save it.

Keep the key in that secret setting; do not add it to a code file or README.
If GitHub hides a button on your phone, use your browser's **Request Desktop
Website** / **Desktop site** option.

## 2. Check the connection

1. Open **Actions → Protoface video (phone friendly)**.
2. Tap **Run workflow**, leaving `action` as **check_connection**.
3. Open the finished run. Its Summary should say **Protoface connection
   successful**. This does not submit a paid generation.

## 3. Make a video

1. Tap **Run workflow** again and set `action` to **generate_video**.
2. Replace `prompt` with what you want. The model is **MiniMax H3**.
3. Choose a duration, quality, and video shape; `9:16` is vertical for a phone.
   Leave the defaults for the documented 8-second, 768p, 16:9 example.
4. Tick **confirm_spend** to authorize one paid video, then **Run workflow**.
5. Open the run's **Summary** and tap **Open / download video** when it finishes.
   Save the file to your phone before the provider link expires.

Prices vary. Check current rates in Protoface before generating. The accepted
run's credit estimate is displayed in the Summary, after submission. The
workflow never runs on a schedule, push, or pull request. Each new **Run
workflow** with `generate_video` can charge for another video. GitHub runner
minutes may also count toward your account's limits.

## If it takes too long or fails

The Summary and downloadable artifact contain the `run_...` ID once received.
Choose **check_run** and paste that ID to resume waiting without generating
again. Polling stops after 25 minutes; it does not cancel work at Protoface.
For a network failure during submission, use GitHub's **Re-run jobs** on the
**same run**. It reuses the same idempotency key. A new **Run workflow** creates
a different request and can charge again. A failed/canceled provider run is
reported as a failure; the workflow never resubmits it automatically.

This repository is public: workflow inputs, logs, summaries, and result artifacts
can be visible to other people. Use non-private prompts and content. The API key
is supplied separately from GitHub Secrets and is never printed by this script.

## What is included

- The exact MiniMax H3 request fields from the official quickstart.
- Live input-schema validation and a quota check before submitting.
- A stable idempotency key for re-running the same GitHub run.
- Lightweight status polling and a result/download link.
- `run-id.json`, `submitted.json`, `status.json`, and `result.json` artifacts
  when those stages have been reached.
- Mocked tests that make no live API calls and spend no Protoface credits.

No key has been added and no video has been generated by installing these files.

Sources: [Inference quickstart](https://docs.protoface.com/guides/model-inference),
[Generate a video](https://docs.protoface.com/guides/generate-video),
[Model input schemas](https://docs.protoface.com/guides/models#request-schemas),
[MCP setup](https://docs.protoface.com/reference/mcp).

